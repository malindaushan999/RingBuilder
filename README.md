# Ring Builder 💎

A comprehensive, interactive ring customization platform built with Lit web components. Design your perfect ring with professional-grade diamond selection, real-time pricing, and multi-currency support.

![Ring Builder](https://img.shields.io/badge/status-production-brightgreen) ![License](https://img.shields.io/badge/license-MIT-blue)

## ✨ Key Features

### 💍 Comprehensive Customization
- **4 Ring Types:** Engagement, Wedding, Eternity, Promise
- **6 Diamond Shapes:** Round, Princess, Oval, Emerald, Cushion, Pear
- **5 Metal Types:** Yellow Gold, White Gold, Rose Gold, Platinum, Silver
- **6 Setting Styles:** Solitaire, Halo, Three Stone, Pavé, Side Stone, Vintage
- **Professional Grading:** Color (D-I), Clarity (FL-SI2), Cut (Excellent-Fair)

### 🎨 Interactive Experience
- **Drag & Drop:** Drag metals and shapes to ring preview
- **Real-time Preview:** 18 unique ring images update instantly
- **Visual Feedback:** Highlights, animations, and smooth transitions
- **Mobile-Friendly:** Touch controls and responsive design

### ❤️ Wishlist System
- Save unlimited custom designs
- Persistent browser storage
- View, compare, and remove saved rings
- Timestamp tracking

### 💰 Smart Pricing
- **Multi-factor Calculation:** 8 pricing components
- **5 Currencies:** USD, EUR, GBP, AUD, CAD
- **Real-time Conversion:** Instant currency updates
- **Dynamic Updates:** Recalculates on every change

### 🌐 Localization
- **English & Spanish** interface
- Automatic label translation
- Currency-specific formatting

### 📋 Share & Export
- **Print Quotes:** Professional print-ready format
- **Email Designs:** Pre-filled mailto with specifications
- **Complete Details:** Images, specs, and pricing

### 🛒 E-commerce Ready
- Add to cart with complete data payload
- Custom event system for integration
- Success notifications
- Ready for checkout implementation

## 🚀 Quick Start

### Local Development

1. **Clone the repository:**
```bash
git clone https://github.com/malindaushan999/RingBuilder.git
cd RingBuilder
```

2. **Install dependencies:**
```bash
npm install
```

3. **Start the development server:**
```bash
npm start
```

4. **Open in browser:**
```
http://localhost:3000
```
