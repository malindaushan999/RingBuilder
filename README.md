# Ring Builder

A beautiful, interactive ring customization widget built with Lit web components.

## Features

- 💍 Interactive ring customization
- 🎨 Metal color picker (Yellow Gold, White Gold, Rose Gold, Platinum, Custom)
- 💎 Diamond shape selection (Round, Princess, Oval)
- ⚖️ Carat weight adjustment
- 🌈 Color grade selection
- 💰 Real-time price calculation
- 🛒 Add to cart functionality
- 📱 Responsive design

## Live Demo

[View Live Demo](https://malindaushan999.github.io/RingBuilder/)

## Local Development

1. Clone the repository:
```bash
git clone https://github.com/malindaushan999/RingBuilder.git
cd RingBuilder
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open http://localhost:3000 in your browser

## Technologies Used

- [Lit](https://lit.dev/) - Web Components
- Express.js - Development server
- HTML5 & CSS3
- JavaScript ES6+

## Deployment

This project is deployed using GitHub Pages. Any push to the `main` branch will automatically deploy to the live site.
